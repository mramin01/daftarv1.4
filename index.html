# دفتر (Daftar) — سامانه جامع مدیریت کارها، شیفت، تقویم جلالی و ماتریس تصمیم‌گیری

**دفتر** یک وب‌اپلیکیشن پیشرفته، راست‌به‌چپ (RTL) و فارسی با طراحی **Black-Mocha Glassmorphism** است که بدون وابستگی به سرور خارجی، تمامی نیازهای مدیریت کارها، ثبت شیفت و رخدادهای پایش (Monitoring/DevOps)، تقویم محاسباتی خالص جلالی (بدون تعطیلات و مناسبت‌های پیش‌فرض)، دفترچه ایده‌ها و ماتریس تصمیم‌گیری را در مرورگر شما فراهم می‌کند.

## ویژگی‌های کلیدی
1. **مدیریت کارها و چک‌لیست**: تعریف کار با اولویت، دسته‌بندی، تاریخ سررسید جلالی، چک‌لیست زیرکارها با محاسبه خودکار درصد پیشرفت و پیوست تصویر یا فایل.
2. **مدیریت شیفت و رخدادهای پایش**: ثبت شیفت‌های صبح، عصر، شب، روزکار و آنکال، محاسبه خودکار ساعت کاری و اضافه‌کاری، و ثبت رخدادهای فنی با محاسبه خودکار شاخص **MTTR**.
3. **تقویم خالص جلالی**: تبدیل دقیق ریاضی تاریخ جلالی و میلادی، تشخیص سال کبیسه و برنامه روزانه (بدون هیچ‌گونه تعطیلات یا مناسبت‌های پیش‌فرض).
4. **ایده‌ها و ماتریس تصمیم‌گیری**: امتیازدهی Impact/Effort به ایده‌ها و ثبت مزایا/معایب و درصد اطمینان تصمیم‌ها.
5. **پشتیبان‌گیری، تست خودکار و خروجی ZIP**: ذخیره‌سازی خودکار در `localStorage` و `IndexedDB`، خروجی/ورودی JSON و اجرای ۱۲ تست خودکار.

## روش اجرای سریع
- **روش ۱ (مستقیم)**: فایل `index.html` را مستقیماً در هر مرورگر مدرنی باز کنید.
- **روش ۲ (سرور محلی)**:
  ```bash
  npx serve .
  # یا
  python3 -m http.server 8080
  ```

## راهنمای انتشار در GitHub Pages
1. یک مخزن (Repository) جدید در گیت‌هاب بسازید.
2. محتویات پوشه پروژه (فایل‌های استخراج‌شده از `daftar-project.zip`) را در شاخه `main` قرار دهید:
   ```bash
   git init
   git add .
   git commit -m "Initial release of Daftar App"
   git branch -M main
   git remote add origin https://github.com/<USERNAME>/<REPO>.git
   git push -u origin main
   ```
3. در گیت‌هاب به بخش **Settings > Pages** بروید، گزینه **Branch** را روی `main` و پوشه `/ (root)` قرار داده و **Save** را بزنید.
